# 99Levers login

Read `../../reference/connection.md`, relative to this skill's base directory,
and follow its connection workflow for the current host.

Register the MCP server when needed, complete browser login with the user,
and verify access through a read-only 99Levers tool call. Do not change app code.
Report whether tools are ready, login is pending, or a session restart is needed.
If setup interrupted another 99Levers skill, resume that task once tools work.
